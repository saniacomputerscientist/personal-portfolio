Basic tags Completed
<html> This is main root element that contains the whole webpage code.
<head> This tag in HTML is used to store metadata and machine-readable information about the document that is not displayed directly on the webpage.
<meta> This tag in HTML provides hidden information (metadata) about a webpage to browsers and search engines.
<title> This tag in HTML is used to define the title of a webpage, which appears on the browser tab and in search engine results.
<body> This tag contains all the visible content of a webpage, such as text, images, links, and buttons that users see on their screen.

Anchor tag
<a>		 Used to add links to your page.
For example: <a href="http://google.com">Google</a>
Image tag
<img> 		Used to add image to your page.
For example:<img src="/image.png"alt="Random Image">
<br> Used to next line (line breaks) to your page.
<b> Used to bold text.
<i> This tag in HTML italicizes text to mark it as different from the surrounding text, such as technical terms or foreign words.
<u> Used to underline text.
<hr> Used to display a horizental ruler, used to separate content.
<big> Used to dispaly big text on your page.
<small> Used to display small text on your page.
Subscript tag
<sub> 		(subscript) tag is used to display text half a character below the normal line in a smaller font, which is commonly used for chemical formulas (like H₂O) and mathematical variables (like x₁).
Superscript tag
<sup>		 This tag makes text smaller and raises it higher, for example: E = mc2
<pre> Used to display text as it is(without ignoring space & next line).
