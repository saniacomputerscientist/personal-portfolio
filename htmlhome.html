What is HTML?

HTML (Hypertext Markup Language) is the standard code used to build the structure of a web page. It acts as the skeleton of a website, telling the browser how to display text, images, links, and other content.

First HTML file

index.html

It is the default name for a website's homepage

HTML tag

A container for some content or other HTML tags

<p> This is paragraph tag</p>


Basic HTML page

<!DOCTYPE html>
<html>
<head>
<title> MY first page</title>
</head>
<p> Hello world!</p>
</body>
</html>

Quick points

  • HTML is a parent of head & body tag.
  • Most of HTML elements have opening & closing tags with content in between.
  • Some tags have no content in between, eg: <br>.
  • We can use inspect element or view page source to edit html.

Comments in HTML

This is a part of code that should not be parsed.
<!--- This is an HTML Comment---->

HTML is NOT case sensitive

<html> = <HTML>
<p> = <P>
<head> = <HEAD>
<body> = <BODY>
