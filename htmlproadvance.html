Page layout Techniques

Using the semantic tags for layouts.
Using the right tags.
<header>:The <header>tag is a visible HTML element used to group introductory content, logos, and main navigation links at the top of a webpage or a specific section.
<main>:The <main> tag defines the dominant, unique, and central content of an HTML document's body.
<footer>: The <footer>tag defines the bottom section of a webpage or document, typically containing copyright info, contact data, and site links.

Inside Main Tag

Section Tag: For a section on your page.
<section>
Article Tag: For an article on your page.
<article>
Aside tag: For content aside main content(ads).
<aside>

Revisiting Anchor tag

  • <a href="https://google.com" target="_blank">Google</a>
    Note:The target="_blank"attribute is used to open this link in a new tab.

  • <a href="https://google.com"> <img src="link"></a>

    • Note:The img src="link"attribute is used for clickable pic.

Revisiting Image Tag

  • <img src="link" height="50">
    Note:The height=50px attribute is used to set height.

  • <img src="link" width="50">
    Note:The width=50px attribute is used to set width.
